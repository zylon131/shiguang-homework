# 拾光 · 托管错题本

面向托管机构老师的手机网页，覆盖小学 1—6 年级语文、数学、英语。从零开发于本目录，模型配置读取本目录 `.env` 和 `.env.minimax`；密钥仅在服务端使用。

公网试用入口：**https://8.130.50.140**。首次使用点击「开通试用」，机构邀请码见本机 `deploy/ACCESS.local.txt`。服务器部署记录见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 当前可用流程

1. 机构管理员凭邀请码开通机构，邀请老师；批量粘贴学生姓名，分配年级、班级及负责老师。
2. 手机选择学生和科目，拍照或从相册一次选择最多 12 页。客户端压缩、服务端去除图片元数据，上传完成后立即继续下一位。
3. 后台并发识别和批改；任务、照片和结果持久保存，服务重启会恢复未完成任务。失败可重试，重复提交用幂等键防止重复任务。
4. 只有模型判断正确且置信度至少 0.92 的题目自动通过。疑似错题、低置信度、主观题和不完整题交给老师确认；可查看原图、修改题干和答案、排除无法判定的题。学生详情可查看逐题记录并纠正自动判定。
5. 确认错题且已匹配标准知识点后自动生成 3 道同知识点练习，分基础、巩固、提升；可查看答案、直接编辑题目及解析、打印、标记掌握。出题结果需要老师核对。
6. 按中国时区的自然周汇总，可一键准备全班周报。周报包含作业记录、已判定题正确率、薄弱知识点、已生成的练习和老师留言。待确认和被排除的题不计入正确率。每份报告最多收录 10 组练习，并明确提示尚未生成或未收录的数量；全部练习仍保存在错题本。
7. 老师预览后生成分享链接和 6 位访问码，在微信粘贴发送。家长无需注册。链接 14 天过期，可重新生成或撤销；重新生成会使旧链接失效。分享后冻结报告快照，需先撤销才能更新内容。

## 本机启动

需要 **Node.js 24+**。Windows 可直接执行：

```powershell
cd 'E:\mzl\vibe coding\托管错题本'
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

脚本优先使用系统 Node 24；系统版本过低时尝试本机 Codex 提供的 Node 运行时，不会改动系统安装。打开 `http://localhost:8787`。按 Ctrl+C 停止。

标准启动方式（Node 24 环境）：

```sh
npm ci
npm run build
npm start
```

开发模式：`npm run dev` 或 `start.ps1 -Dev`，前端 5173，后端 8787。

本地默认开放「体验老师工作台」：每次进入建立独立、含虚构数据的体验机构。体验页面始终标注示例；上传自己的图片会使用真实 MiniMax API。机构注册的本地邀请码为 `LOCAL-PILOT-2026`；本地注册页面会预填。

手机与电脑同一 Wi-Fi 时，可通过 `http://电脑局域网IP:8787` 访问，需要网络允许手机连接该端口。网页使用系统文件选择器的相机入口与相册入口。正式微信使用应部署至 HTTPS 域名。当前分享链接使用打开页面的域名；localhost 和局域网链接不能供外网家长访问。

## 配置

将 `.env.example` 复制为 `.env` 并按需填写。已有 `.env.minimax` 可以继续保留，不要加入版本控制。已有进程环境变量优先，其次 `.env`，再次 `.env.minimax`。

| 参数 | 用途 |
| --- | --- |
| MINIMAX_API_KEY / BASE_URL / MODEL | MiniMax 鉴权、兼容 OpenAI 的 API 地址、模型名（当前 MiniMax-M3） |
| APP_ORIGIN | 前端完整来源，生产必须为 HTTPS，不能带结尾斜线 |
| PILOT_INVITE_CODE | 机构试用邀请码，生产必须为至少 20 位私密值 |
| ENABLE_DEMO | 仅本地体验使用；生产必须 false |
| MODEL_CONCURRENCY | 批改与出题共享并发数，默认 3，允许 1—8 |
| DATA_DIR | 数据目录，默认本目录的 data |
| HOST / PORT | 监听地址和端口，默认 0.0.0.0:8787 |
| TRUST_PROXY | 部署在一个受信反向代理后时设为 1 |

## 标准知识点

直接使用 `tag-data/math.ts`、`english.ts` 和补充后的 `chinese.ts` 小学一年级到六年级的原始标签；不读取初高中或其他科目的条目。`server/curriculum.js` 展平章/节下的 tags、去重；`server/model.js` 根据学生年级和科目将候选列表注入 System Prompt。服务端对返回的 knowledge 再进行精确匹配，老师编辑同样只能从候选下拉列表选择。

| 学科 | 一年级 | 二年级 | 三年级 | 四年级 | 五年级 | 六年级 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 语文 | 25 | 25 | 22 | 20 | 19 | 24 |
| 数学 | 12 | 13 | 12 | 14 | 16 | 14 |
| 英语 | 15 | 10 | 10 | 9 | 6 | 4 |

无法匹配、复习其他年级或大纲未覆盖的题目保留为「待归类」，不强行映射相近标签；该状态不影响判题，错题仍进入错题本和正确率统计，但不计入具体薄弱知识点、不生成缺乏明确知识点依据的练习。历史记录中有效的小学标签在学生升年级后仍能用于周报。大纲标签标准化不代表模型对题意、标签匹配或答案的判断绝对准确，仍保留老师复核。

## 验证

```sh
npm test
npm run build
node scripts/browser-check.js
node scripts/upload-ui-check.js
```

`npm test` 使用独立测试库和本地模型模拟服务，不消耗模型额度，覆盖机构隔离、账号、CSRF 来源校验、老师权限、文件授权、上传幂等、后台识别、保守判定、出题、报告统计、访问码、分享撤销与邀请重用。

浏览器脚本需要应用已启动及本机 Microsoft Edge，验证桌面与 390px 手机宽度的主要页面、确认、练习和家长分享。截图在 `test-results/browser/`。

`upload-ui-check.js` 通过测试专用的网络拦截验证手机压缩、上传失败保留照片、幂等重试、切换科目和全班周报；不会调用真实模型。产品本身的上传仍使用真实后端。

以下检查会调用真实模型、消耗当前账号的 API 额度，只在需要联调时运行：

```sh
npm run check:model
node scripts/check-curriculum-model.js
node scripts/live-check.js
```

`live-check.js` 上传本地生成的语数英合成练习图片，检查批改、确认、3 道练习、周报及分享的完整流程；不使用真实学生资料。证据位于 `test-results/live/`。合成题目验证不等同于真实手写作业准确率或班级耗时评测。

`check-curriculum-model.js` 针对三科验证实际 Prompt 注入、标准标签及基础判题；可通过 `CHECK_SUBJECT` 仅检查一个科目。`production-check.js` 是部署人员专用的公网验收脚本，会创建独立的临时验收机构；测试完应按 `DEPLOYMENT.md` 清理，普通老师无需运行。

## 部署与数据

提供 `Dockerfile` 与 `compose.yaml`。在 `.env` 设置 HTTPS 的 `APP_ORIGIN`、私密机构邀请码，并保留 `.env.minimax`；执行 `docker compose up -d --build`，由反向代理将 HTTPS 请求转发至 `127.0.0.1:8787`。镜像不复制 env、照片、数据库或测试记录。生产采用 HttpOnly、Secure、SameSite 会话 Cookie，禁用体验入口。

数据存放在 `data/app.sqlite` 和 `data/uploads/`。数据库使用 WAL，图片经过鉴权接口读取，不能直接访问静态路径。会话、分享链接和邀请令牌只保存摘要，密码使用 bcrypt；机构和学生访问权限在服务端校验。审核操作有审计记录。

备份：停止应用后运行 `node scripts/backup.js`，数据库一致快照与照片备份写入 `data/backups/时间戳/`。恢复时应停止服务，将快照数据库和 uploads 作为一组恢复，并妥善处理旧 WAL 文件。生产需将备份复制到独立存储并测试恢复。

这是**面向受邀机构的单实例试用版本**：SQLite 与本地照片目录、数据库持久任务队列、单进程 worker。不要直接启动多个应用副本共享同一库；扩大到大量机构时应迁移 PostgreSQL、对象存储和具备任务租约的独立队列，并补齐配额计费、机构生命周期与可观测性。

目前没有在线收费、短信找回密码、微信自动发消息或定时自动发周报；老师在周报页批量准备并手动分享。已部署公网 HTTPS IP 入口，尚未绑定自有域名。大量真实手写、作文、图形题和不同教材版本仍需机构样本验证；不确定题保持人工复核。老师操作与模型计算分离，以减少等待，但不承诺几十页作业的固定处理时长。

模型说明：[MiniMax-M3 官方介绍](https://www.minimaxi.com/models/text/m3)。
