# 托管错题本 · 知识点大纲数据 (tag-data)

本目录从原系统完整迁移而来，包含各学科标准的树状课标知识点定义。

## 1. 核心文件清单

| 文件 | 学科 | 包含学段与内容特点 |
| :--- | :--- | :--- |
| **math.ts** | 数学 | **小学 1—6 年级**、初中 7—9 年级、高中（数的认识、四则加减乘除、几何图形、简易方程等） |
| **english.ts** | 英语 | **小学 1—6 年级**、初中、高中（字母语音、核心词汇、Be动词/现在进行时/There be等语法句型） |
| **chinese.ts** | 语文 (已完整补充) | **小学 1—6 年级部编版核心考点**（拼音、笔画笔顺、多音字、查字典、词语成语、句式转换/病句/修辞、小古文、现代文阅读、写话习作）及初高中 |
| **physics.ts** | 物理 | 初高中力学、声现象、光学、热学、电学 |
| **chemistry.ts**| 化学 | 初高中物质变化、化学方程式、酸碱盐 |
| **biology.ts** | 生物 | 细胞、动植物生理、遗传与变异 |

## 2. 数据结构规范

数据以两张表/字典导出：
1. XXX_GRADE_ORDER: 年级排序索引
2. XXX_CURRICULUM: 标准树状大纲
   - **年级** (Grade, 如 '三年级')
     - **章节** (Chapter, 如 '数的认识')
       - **小节** (Section, 如 '分数的初步认识')
         - **具体考点** (Tags, 如 ['分数的初步认识', '几分之一', '几分之几'])

## 3. 接入 Prompt 约束指导 (方式 B 实践)

在 \server/model.js\ 中调用 MiniMax-M3 批改题目时：
1. 根据当前学生的 \student.grade\（如 3 年级）和 \subject\（数学），提取对应年级的可用知识点标签列表；
2. 注入 System Prompt：
   > \'识别出错题后，knowledge 字段必须优先从以下官方知识点列表中选择最贴切的一项：[...tags]\'
3. 模型将输出标准的大纲标签，避免无序的随意命名，使得周报与薄弱点统计 100% 准确。
